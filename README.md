# Keykin for Umbrel

A community app store with two apps:

- **Keykin Box**: the always-on piece of your Nostr key, and the admin page. Private.
- **Keykin Login**: the account page and the outside door. Public, behind your own reverse proxy.

Add this store in Umbrel under App Store, Community App Stores, with this repository's address.
Install Keykin Box first.

The code is at https://github.com/sybenx/keykin.
